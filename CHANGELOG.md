## [1.0.0] - 2026-11-06

### Added

- `writing-launch-copy` (Free): landing page, store listing, Product Hunt, and Show HN copy from repo facts, with `[[ASK]]` markers for anything missing.
- `polishing-readme` (Free): audits the repo, writes an above-the-fold README block, and creates or verifies `CHANGELOG.md`.
- `writing-seo-articles` (Pro): intent line, outline, drafted article with runnable proof, and a metadata block.
- `writing-release-notes` (Pro): classified release notes from the diff since the last tag, prepended to `CHANGELOG.md`, with GitHub Release and store variants.
- `writing-pricing-pages` (Pro): pricing model choice, free/paid line, tier cards, risk reversers, and FAQ.
- `running-launch-checklist` (Pro): 15-item pre-launch verification with evidence and a READY / NOT READY verdict.
- `build.sh`: packages the Free (MIT) and Pro zips into `dist/`.
